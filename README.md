💰 Gestor de Gastos em Python

Olá! Seja bem-vindo ao meu projeto!

O Gestor de Gastos é um projeto pessoal que desenvolvi com o objetivo de colocar em prática meus conhecimentos em Python e, ao mesmo tempo, criar uma ferramenta simples para ajudar no controle de despesas do dia a dia.

A ideia é desenvolver um sistema que permita registrar produtos, acompanhar os gastos e consultar um extrato diretamente pelo terminal.

Este projeto também faz parte da minha jornada de aprendizado em programação. Por isso, ele está em constante evolução: cada melhoria representa uma oportunidade de aprender algo novo, resolver problemas e escrever um código melhor.

✨ Funcionalidades

- Cadastro de despesas: permite registrar produtos informando descrição, valor unitário e quantidade.
- Validação de dados: verifica as informações digitadas e trata erros, como inserir letras no lugar de números.
- Consulta de despesas: apresenta os produtos cadastrados e seus respectivos valores.
- Remoção de itens: permite remover produtos ou ajustar suas quantidades.
- Cálculo de subtotais: calcula automaticamente o valor de cada produto com base na quantidade e no preço unitário.
- Cálculo do total: soma os subtotais e apresenta o valor total das despesas.
- Persistência de dados: utiliza um arquivo de texto ("gastos.txt") para armazenar os registros e recuperá-los quando o programa é iniciado.
- Menu interativo: permite navegar pelas funcionalidades e encerrar o programa com confirmação.

🚀 Como executar o projeto

É necessário ter o Python 3 instalado.

1. Clone este repositório:
   
   git clone https://github.com/0xrafaelsec/Gestor-de-gastos-python.git

2. Entre na pasta do projeto.

3. Execute o arquivo principal:
   
   python gestor-de-gastos.py

Também é possível executar o projeto utilizando editores como VS Code e PyCharm, ou pelo celular com aplicativos como Pydroid 3.
