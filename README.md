# Gestor de Gastos em Python

Um projeto simples desenvolvido em Python para o registo e acompanhamento de despesas pessoais através da linha de comandos (terminal). 

## Funcionalidades

- **Registo de Despesas:** Permite adicionar o nome e o valor de cada gasto.
- **Extrato Detalhado:** Lista todos os itens comprados com os respetivos valores formatados (ex: R$ 23.90).
- **Cálculo Automático:** Soma e apresenta o valor total gasto durante a sessão.
- **Menu Interativo:** Ciclo contínuo que mantém o programa a correr até que o utilizador decida sair.

## Tecnologias Utilizadas

- **Python 3:** Estruturas de repetição (`while`, `for`), condicionais (`if`, `elif`), listas e formatação de strings (f-strings).

## Como executar o projeto

1. Certifique-se de que tem o Python instalado na sua máquina ou no telemóvel (ex: Pydroid 3).
2. Faça o clone deste repositório ou guarde o ficheiro principal.
3. Execute o programa no terminal:
   ```bash
   python gestor-de-gastos.py
   ```
